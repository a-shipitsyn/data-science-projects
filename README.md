# Data science projects

[![tests](https://github.com/a-shipitsyn/data-science-projects/actions/workflows/tests.yml/badge.svg)](https://github.com/a-shipitsyn/data-science-projects/actions/workflows/tests.yml)

Fourteen self-contained data science and machine learning projects in Python: credit risk,
experimentation and causal inference, marketing econometrics, recommender systems, NLP and
LLM systems, computer vision, audio, bioinformatics and trading. Each folder has its own
README with the task, method, results and instructions, its own `requirements.txt`, and
tests where the project is a system rather than an analysis.

No proprietary data is included. Most projects run on **simulated data with a known ground
truth**, generated by the project's own simulator, so every model can be checked against the
true mechanism, not only against held-out data.

Contact: Aleksey Shipitsyn, [LinkedIn](https://www.linkedin.com/in/aleksey-shipitsyn-53417431)

## Projects

### Credit risk and prediction on tabular data

| Project | What it does | Methods |
|---|---|---|
| [loan-default-prediction](loan-default-prediction/) | Default probability for point-of-sale loans, approve / decline at a chosen risk level, REST API | logistic regression, gradient boosting, neural network, REINFORCE classifiers; calibration, imbalanced accuracy, repeated cross-validation with significance tests, out-of-time holdout, drift monitoring |
| [debt-payment-likelihood](debt-payment-likelihood/) | Probability that a debtor pays within 3, 6 and 12 months, and the expected amount | financial-ratio features, XGBoost, imbalanced classification |
| [metal-profile-pricing-engine](metal-profile-pricing-engine/) | Multi-tenant service that learns each manufacturer's pricing from past quotes and quotes new profiles with a 90 % interval | gradient boosting, Bayesian tuning (Optuna), conformal intervals, time-based validation, champion/challenger retraining, encrypted per-tenant storage, FastAPI |

### Experimentation, marketing and recommendation

| Project | What it does | Methods |
|---|---|---|
| [ab-testing-experimentation](ab-testing-experimentation/) | Plans, monitors and reads out an online A/B test, and finds which users the change helps or harms | power analysis, CUPED and regression adjustment, delta method, sample ratio mismatch check, group sequential tests (O'Brien-Fleming alpha spending), mSPRT, uplift modelling (EconML causal forest, DR- and X-learners), doubly robust segment effects, Qini curves |
| [did-synthetic-control](did-synthetic-control/) | Measures the sales effect of a store launch that was not randomised: a pilot in selected stores, a staggered rollout and a single-region launch | difference-in-differences (2×2, doubly robust, TWFE, event study), Hotelling pre-trend test, Callaway-Sant'Anna, imputation estimator, TWFE negative-weight diagnostic; synthetic control, augmented synthetic control, synthetic DiD, placebo inference |
| [marketing-mix-modeling](marketing-mix-modeling/) | How TV, outdoor and digital advertising drive daily calls, and how to reallocate the budget | adstock and saturation transforms, regression with assumption tests, time-varying TV effect, Bayesian MMM (PyMC) calibrated with lift tests, budget optimisation |
| [marketplace-recommender-system](marketplace-recommender-system/) | Ranks commercial property listings for businesses on a two-sided rental marketplace | popularity, item-KNN, EASE, implicit ALS, BPR, LightGCN, SASRec, two-tower; two-stage retrieval + LightGBM LambdaRank; time-based split, cold-start segments, oracle comparison |

### Text, LLM and retrieval

| Project | What it does | Methods |
|---|---|---|
| [research-paper-knowledge-base](research-paper-knowledge-base/) | Searches arXiv by topic, builds a local knowledge base and answers complex questions with citations | hybrid BM25 + dense retrieval (Chroma), question decomposition RAG, local LLM (Ollama), retrieval and answer evaluation |
| [rag-support-telegram-bot](rag-support-telegram-bot/) | Technical-support Telegram bot answering questions from product manuals | RAG with LlamaParse, OpenAI embeddings, pgvector, Claude; dialogue context, per-user limits |
| [product-review-analytics](product-review-analytics/) | Factors behind star ratings, rating classifier, topics and themes, LLM-written product descriptions | exploratory analysis, text + structured features classifier, keyword topics, theme tagging, LLM prototype with evidence checks |

### Audio, video and sequences

| Project | What it does | Methods |
|---|---|---|
| [call-prosody-classification](call-prosody-classification/) | Predicts whether a sales call ends in a purchase from how the speakers sound | prosodic and acoustic features (pitch, energy, formants, speech rate, laughter), logistic regression, random forest, gradient boosting, MLP; permutation importance |
| [video-human-action-detection](video-human-action-detection/) | Finds people in a video and recognises their actions | YOLOv4 person detection, 3D CNN clip recognition (Kinetics-400), spatio-temporal action detection (PyTorchVideo, AVA) |
| [masked-nucleotide-prediction](masked-nucleotide-prediction/) | Predicts a missing base in a DNA sequence from its context | k-mer context models over 88 million bases with parallel numba, logistic regression, CNN; gene-level split |
